# PS5 Stock Monitor — Germany

Monitor three Sony PlayStation 5 product variants in Germany, using GitHub Actions, a Python HTML parser and a static web dashboard.

| Product | Storage | Telegram stock alerts |
|---|---|---|
| PS5 Disc + 1 DualSense | 1 TB | Yes |
| PS5 Disc + 2 DualSense | 1 TB | Yes |
| PS5 Digital + 2 DualSense | 825 GB | No |

Dashboard: https://mmur1n.github.io/ps-monitor-2/
Actions: https://github.com/mmur1n/ps-monitor-2/actions

The repository is public. The bot token is NOT contained in any repository file. Use GitHub Actions Secrets instead.

## How it works

- A scheduled GitHub Actions run checks Sony public HTML pages approximately every five minutes. Actions is serverless: every run starts an ephemeral runner, performs three requests, and shuts down. The schedule is best-effort, not a real-time guarantee.
- The parser validates the selected product's H1 and specifications, then considers out-of-stock or cart-action text near the product. HTTP errors, bot challenges or unexpected markup produce ERROR or UNKNOWN; they NEVER produce a false unavailable status or notification.
- State and history are stored in docs/data.json and committed by the workflow after each run. GitHub Pages renders them in a browser, including the original HTML excerpts that explain classification.
- A Disc notification is sent only on first observed IN_STOCK status; another notification can be sent after a confirmed OUT_OF_STOCK period. UNKNOWN/ERROR do not reset the alert. Digital stock never triggers a notification.
- Manual workflow runs and status changes provide compressed HTML snapshots as GitHub Actions artifacts (two-day retention). Full HTML isn't committed to the public repository.

## First-time activation (requires repository owner)

1. Settings -> Pages -> Build and deployment -> Source: GitHub Actions.
2. Settings -> Secrets and variables -> Actions -> New repository secret.
   Create TELEGRAM_BOT_TOKEN with a NEW token generated by BotFather, and TELEGRAM_CHAT_ID with your Telegram chat ID.
3. IMPORTANT: A bot token was shared in chat. Use BotFather to revoke the exposed token before setting the new one in GitHub.
4. Send /start to your Telegram bot from the same chat that should receive alerts.
5. Settings -> Actions -> General -> Workflow permissions: choose Read and write permissions if permitted by the repository policy (the workflow requests contents: write).
6. Actions -> PS5 stock monitor -> Run workflow. To verify Telegram delivery, enable test_telegram in that manual run. Then review Actions run summary and the Pages URL.

No pip packages are needed; Python 3.12 standard library only. Local commands:

    python -m unittest -v tests
    python monitor.py --once
    python monitor.py --interval 300

The site is unofficial, read-only, does not log in, bypass anti-bot measures, reserve or buy a console. The availability detection is best-effort and depends on Sony HTML markup and access from GitHub infrastructure.
